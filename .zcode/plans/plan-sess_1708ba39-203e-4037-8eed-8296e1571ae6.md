### 🗺️ ClustrMaps Setup (User Action Required)
After implementation, you'll need to:
1. Go to [clustrmaps.com](https://clustrmaps.com/) → Sign up (free)
2. Add your site URL → Copy the generated `id` from the embed code
3. Set `clustrmaps.id` in `_config.yml`

The widget will not display until the ID is configured.
